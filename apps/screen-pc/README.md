# Titan Screen — экран Titan HUB на компьютере с Windows

Ноутбук или ПК с телевизором по HDMI. На **основном мониторе** — окно управления, на
**телевизоре** (второй монитор) — показ экрана из «Управление → Экраны»: меню, картинки,
реклама в ленте — то же, что показывает приставка Titan Menu (`/screen/<id>`).

- Electron 39, Windows 10/11 x64. Пакет `ru.titan.screen`, установщик NSIS.
- **Монитор для показа** и **как висит ТВ** (0° / 90° / 270°) хранятся на сервере
  (`screens.display_id`, `rotation`): их меняют и в приложении, и в HUB. Изменение в HUB
  приходит по потоку `/screens/device/stream` сигналом `settings` — показ переезжает сразу.
- Мониторы компьютера уходят в HUB в пульсе раз в 20 с (`device_state.displays`), там из
  них выбирают так же, как в приложении. «Сам выберет» — первый не основной монитор;
  выбранный монитор отключили — показ ждёт его и сам на другой не переходит.
- «Показать номера» (в приложении, в трее и из HUB) — крупные цифры на всех мониторах.
- Вкладка «Показ и реклама» — страница экрана в HUB (вход сохраняется): картинки, лента,
  тема — правятся там же, где всегда.
- Сообщение на ТВ из HUB, сторож страницы (молчит 90 с — перезагрузка), повтор при обрыве
  сети, экран не гаснет, запуск вместе с Windows (сразу в трей). Закрыть окно — свернуть
  в трей; «Выход» — в меню трея.

## Подключение

1. Скачать и установить: <https://titanpos.ru/apps/screen/TitanScreen-Setup.exe>
   (установщик сам добавит правило брандмауэра для порта 8788).
2. Либо **с телефона**: HUB → Управление → Экраны → «Подключить ТВ» — телефон найдёт
   компьютер в той же сети по коду на его экране;
   либо **кодом**: в HUB (веб) на странице экрана → «Подключить компьютер с Windows» →
   ввести адрес клуба и код из 8 знаков в Titan Screen.
3. Подключить ТВ по HDMI — показ появится на нём сам. Нужен другой монитор — выбрать в
   приложении или в HUB.

## Сборка и выпуск

```bash
cd apps/screen-pc
npm ci
npm test                 # выбор монитора, разбор потока, адрес клуба
npm start                # запуск из исходников (автозапуск при этом не включается)
npm run dist:win         # → dist/TitanScreen-Setup-<версия>.exe (на Mac тоже, без Wine)
bash ../../scripts/publish-screen-pc.sh   # на titanpos.ru/apps/screen/
```

Новая версия — поднять `version` в `package.json`. Подписи кода нет: Windows SmartScreen
при первой установке покажет «Неизвестный издатель» → «Подробнее» → «Выполнить в любом случае».

Не входит в pnpm-воркспейс (свой npm), в серверные сборки не попадает.
