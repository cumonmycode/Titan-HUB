# MafBoard — архитектура ядра

Приложение-компаньон ведущего: рассадка, раздача ролей, фазы игры, голосования, фолы,
итоги и рейтинги. Сначала iOS (SwiftUI, iOS 26+), затем Android.

## Принципы

1. **Ядро — чистый Swift + Foundation.** Никаких SwiftUI/SwiftData/Combine в `MafBoardCore`.
   Ядро тестируется на macOS за секунды и в будущем собирается под Android (Swift SDK for Android).
   Его же может использовать сервер на Swift.
2. **Движок — чистая функция.** `GameEngine.apply(action, to: state, at: date) -> newState`.
   Нет таймеров, сети и чтения часов внутри. Ошибка не меняет игру.
3. **Игра = исходные данные + журнал действий.** Состояние всегда выводится из журнала.
   Отмена шага, восстановление после падения и просмотр «хода игры» получаются сами собой.
4. **Правила — это данные.** Движок не знает слов «спортивная» и «городская» — он читает `Ruleset`.
   Пресеты `.sport` и `.city` копируются и правятся под регламент клуба.
5. **История неизменна.** Завершённая игра хранит снимок правил и баллов. Если позже поменять
   систему оценки, старые игры не пересчитаются, пока явно этого не попросить.

## Структура пакета

| Папка | Что внутри |
|---|---|
| `Domain/` | `Seat`, `Role` + `Team`, `PlayerProfile`, типобезопасные `PlayerID`/`GameID`/`SeriesID` |
| `Rules/` | `GameVariant`, `Ruleset` с пресетами, составы ролей, политики дня/голосования/ночи/дисциплины/лучшего хода |
| `Engine/` | `GameSetup`, `GameState`, `GamePhase`, `GameAction`, `GameEvent`, `GameError`, `GameEngine` + переходы по фазам, `GameSession` (журнал и отмена) |
| `Accounts/` | `UserAccount`, `TelegramIdentity`, `GoMafiaPlayer`/`GoMafiaClub`/`GoMafiaLink`, `HostingAccess`, `TelegramLoginFlow` |
| `Setup/` | Случайная рассадка, раздача ролей, воспроизводимый генератор |
| `Scoring/` | `CompetitionFormat` (фанка/рейтинг/миникап/турнир), `Points`, `ScoringPolicy`, `GameScorer` |
| `Records/` | `GameRecord` (завершённая игра), `Series` (вечер, миникап, турнир) |
| `Standings/` | Таблицы за серию или период с тай-брейками и общими местами |
| `Persistence/` | Протоколы хранилищ и `InMemoryStore` |
| `Timing/` | `Countdown`: таймер от дат, не сбивается при сворачивании |
| `MafBoardClient/` | `MafBoardAPI` (протокол для подмены в превью) и `MafBoardAPIClient` поверх `URLSession` |

## Как идёт игра

```
Нулевая ночь (договорка / знакомство → свободная посадка)
        │
        ▼
┌─► День N ─ прощальные речи убитых ночью (+ лучший ход после ночи 1)
│      │
│      ├─ речи по кругу (открывает следующий живой после вчерашнего открывавшего;
│      │  лишённые слова пропускаются; в спортивной кандидатуру выставляет только говорящий)
│      ├─ доп. шаги дня (городская: добор в день 1, общая минута в день 2+)
│      ├─ решение: голосования нет / одна кандидатура / голосование
│      │     основной круг → попил: оправдания → переголосование
│      │     → повторный попил: «поднять всех» (спортивная) / никто (городская)
│      ├─ прощальные речи выбывших
│      └─ сумерки
│      ▼
│   Ночь N ─ шаги по очереди (выстрел мафии, ход маньяка, проверки дона и шерифа, доктор);
│      │     шаг пропускается, если нет живого исполнителя
│      ▼
└── разбор ночи: лечение и неуязвимость спасают, остальные цели выбывают

Проверка победы — после любого выбывания (голосование, ночь, удаление, решение ведущего):
мирные — когда чёрных не осталось; мафия — когда чёрных не меньше, чем красных.
```

Если игрок выбывает посреди фазы (удаление, решение ведущего), движок сразу:
- передаёт слово следующему, если выбывший говорил;
- пропускает его ночной шаг;
- убирает его из кандидатур;
- в спортивной отменяет голосование дня.

Выстрел по игроку, удалённому той же ночью, ни на что не влияет.

Интерфейсу не нужно разбирать фазы самому:
- `state.currentStep` говорит, что сейчас происходит (речь №5, голосование за [3, 8], проверка шерифа…);
- `state.timerSeconds` — сколько ставить на таймер;
- `state.canAdvance` — активна ли кнопка «Далее» (`.advance`).

Ошибки типизированы (`GameError` с причинами `SetupProblem`, `Restriction`, `BallotProblem`…),
текст для ведущего — `error.message`.

### Действия ведущего (`GameAction`)

| Действие | Когда |
|---|---|
| `.advance` | «Далее»: закончить речь/таймер/прощание/день; ночью — пропустить шаг |
| `.nominate`, `.withdrawNomination` | Во время речей (спортивная) |
| `.submitBallot` | Голосование: кто за кого, «по рукам» или «поднять всех» |
| `.night(.shot / .check / .heal / .skip)` | Текущий шаг ночи |
| `.foul`, `.techFoul`, `.warning`, `.cancel…`, `.disqualify` | В любой момент игры |
| `.eliminateByHost` | Ручное выбывание без штрафа (роли, которые движок пока не ведёт) |
| `.recordBestMove` | После первой ночи, игроку с правом лучшего хода |
| `.declareOutcome`, `.adjustScore` | ППК, ничья, доп. баллы и штрафы ведущего |

## Аккаунты, GoMafia и история клуба

- **Вход только через Telegram-бота.** Порядок: соглашение → номер телефона → подтверждение → возврат в приложение по Universal Link. `TelegramLoginFlow` — чистый конечный автомат: события на вход, команды «запросить билет / открыть бота / завершить вход» на выход. Подробности и требования к боту — [API.md](API.md).
- **GoMafia по желанию.** Пароль проверяется сервером через вход в GoMafia и нигде не хранится. После привязки подтягиваются профиль (ELO, турниры, аватар) и клуб.
- **Права ведущего (`HostingAccess`):**

  | Аккаунт | Режимы | Куда идут игры |
  |---|---|---|
  | Без GoMafia | только фанка | личная история |
  | GoMafia без клуба | только фанка | личная история |
  | GoMafia + клуб | все режимы | история клуба |

  `GameSetup.hosted(by:…)` проверяет права до старта и записывает в игру ведущего и клуб (`HostContext`).
- **Игроки из GoMafia** получают постоянный `PlayerID.goMafia(id)`: один и тот же на всех устройствах и на сервере. Поэтому таблица клуба, собранная от разных ведущих, сходится. Гость без GoMafia может играть только в фанке.

## Режимы и рейтинги

| Режим | Таблица | Как считается |
|---|---|---|
| Фанка | нет | Результат только за игру. Игра остаётся в истории, но в таблицы не идёт |
| Рейтинг | серия (вечер) и любой период | Сумма баллов за все игры формата `rating` |
| Миникап | своя серия | То же, но отдельный пул: никогда не смешивается с рейтингом |
| Турнир | своя серия | Отдельное мероприятие со своей таблицей |

Таблица строится одной функцией:
`StandingsCalculator.standings(StandingsQuery(format:scope:variant:), from: records)`.
`scope` — `.series(id)`, `.period(DateInterval)` (полуинтервал: игра на границе попадает только в один период)
или `.allTime`. Тай-брейки по умолчанию: баллы → победы → доп. баллы → меньше штрафов.
При полном равенстве места общие (1, 1, 3).

Баллы за игру (`ScoringPolicy.standard`, перенесено из старой версии):
- победа — 1;
- лучший ход — 0.1 / 0.3 / 0.6 за 1 / 2 / 3 угаданных чёрных (только красным);
- удаление — −1;
- техфол — −0.3.

Плюс ручные корректировки ведущего. Каждый балл хранится с расшифровкой «за что».

## Отличия правил

| | Спортивная | Городская |
|---|---|---|
| Игроков | 10 | 8–20 |
| Роли | дон, 2 мафии, шериф, 6 мирных | таблица по числу игроков; на 17+ ведущий выбирает доп. роли |
| Нулевая ночь | договорка 60 с, свободная посадка 40 с | знакомство 60 с, свободная посадка 20 с |
| Кандидаты | выставляет говорящий | все живые |
| Голосование | кто за кого; не проголосовавшие — за последнего | количество рук за каждого |
| День 1 | голосование есть; одна кандидатура — не голосуем | голосования нет, добор 30 с первому игроку |
| День 2+ | одна кандидатура уходит без голосования | общая минута 60 с, затем голосование |
| Повторный попил | «поднять всех» (> половины живых) | никто не уходит |
| Ночь | выстрел, дон, шериф | + маньяк, доктор (не лечит одного дважды подряд); бессмертного не убить ночью |
| Удаление днём | отменяет голосование дня | не отменяет |
| Фолы | 3-й — пропуск речи, 4-й — удаление; 2 техфола — удаление | так же (настраивается) |
| Лучший ход | 3 номера | 2–5 номеров по числу игроков |

## Подключение интерфейса (следующий шаг)

```swift
@Observable @MainActor
final class GameController {
    private(set) var session: GameSession
    var errorMessage: String?

    func send(_ action: GameAction) {
        do { try session.perform(action) }
        catch { errorMessage = error.localizedDescription }
    }
    func undo() { try? session.undo() }
}
```

- Сессия — `Codable` с `schemaVersion`. После каждого действия её кладём в `ActiveGameRepository`, и игра переживает перезапуск. По окончании `GameRecord(session:)` уходит в историю и в `POST /v1/games`.
- `GameState ==` сравнивает весь журнал событий. В SwiftUI лучше следить за нужными полями (`currentStep`, `seats`), а не за всем состоянием.
- Правило совместимости: новая версия движка обязана воспроизводить журналы старых версий. Если это невозможно — поднимаем `schemaVersion` и пишем миграцию.

## Что принято по умолчанию — нужно подтвердить

Где регламент клуба был неизвестен, взяты правила ФИИМ или поведение старого MafBoard.
Всё это настройки `Ruleset`/`ScoringPolicy`/`HostingAccess`, их легко поменять.

1. **Спортивная, день 2+:** единственная кандидатура уходит без голосования.
2. **Попил:** если лидеров в переголосовании стало меньше — ещё круг попила только между ними; если те же — «поднять всех» (проходит при голосах «за» > половины живых).
3. **Удаление днём** в спортивной отменяет голосование этого дня.
4. **Лучший ход** — только у убитого мафией в первую ночь, только для красных.
5. **Городская:** маньяк считается чёрным (как в старой версии) — и для победы, и для проверки шерифа; бессмертный неуязвим ночью; «добор» — 30 с первому игроку дня 1, лишённый слова его не получает.
6. **Роли без автоматики:** детектив, тюремщик, проститутка, телохранитель, лунатик, журналист, священник, судья, камикадзе, красотка, оябун, якудза, потрошитель, аферист, вор, стукач, поклонница, адвокат. Сейчас их последствия ведущий отмечает вручную — нужны правила.
7. **Баллы по режимам** пока одинаковые. Не перенесены компенсация за раннюю смерть (Ci), а также протокол и мнение первого убиенного (в старой версии были в режиме gomafia).
8. **Ничья** объявляется вручную (`.declareOutcome(.draw)`): автоматического правила нет.
9. **GoMafia без клуба** — только фанка, игры в личную историю.
10. **В рейтинг, миникап и турнир** — только игроки с GoMafia; гости — только в фанку.
